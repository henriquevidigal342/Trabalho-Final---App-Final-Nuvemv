# Dicas de Filmes

Primeiro commit do aplicativo de dicas de filmes, feito com Flutter.

## O que já tem

- `lib/main.dart`: tela inicial simples do aplicativo.
- `lib/models/filme.dart`: modelo de dados do filme (título, sinopse, nota, imagem e comentário).
- Dependência `supabase_flutter` adicionada para guardar os filmes na nuvem.

## Como rodar

```bash
flutter pub get
flutter run
```
